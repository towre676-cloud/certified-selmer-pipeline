# Reusable maximal-order certificates beyond 389a1

PerfectJet's generic cubic scout identifies a repeatable maximal-power-order
pattern for monic cubic polynomials \(f\in\mathbf Z[x]\):

1. \(f\) is irreducible over \(\mathbf Q\), checked by the rational-root
   criterion for monic cubics.
2. A translation \(f(x+s)\) is Eisenstein at \(2\), so the order generated by
   its root is locally maximal at \(2\).
3. The power-basis discriminant has squarefree odd part. Every odd prime
   dividing the index would have its square divide that discriminant, which
   is impossible.

Together these prove \(\mathbf Z[\alpha]=\mathcal O_K\) for each listed cubic,
using the standard discriminant-index and Eisenstein local-maximality lemmas.

| Discriminant | Polynomial |
| --- | --- |
| \(148=4\cdot37\) | \(x^3-3x^2-x+1\) |
| \(404=4\cdot101\) | \(x^3-4x^2+2\) |
| \(788=4\cdot197\) | \(x^3-4x^2-2x+2\) |
| \(1076=4\cdot269\) | \(x^3-5x^2-3x+1\) |
| \(1556=4\cdot389\) | \(x^3-x^2-9x+11\) |

The independent replay uses PerfectJet's exact quotient arithmetic to
recompute each discriminant and to find small-prime norm witnesses
\(N(\alpha-k)=-f(k)\).

These are reusable **number-field order** certificates, not Selmer proofs.
Class number, unit completeness, local squareclasses, Kummer maps and Sha
remain separate mathematical tasks. The result also does not claim priority
for the listed number fields; the contribution is the reusable exact
certificate-search and replay infrastructure.
